## What M2 is

M2 v1 is a **forward surrogate** that **amortises the differentiable solver**. Input a
periodic network graph — node positions + per-bond stiffness `k` — and it outputs the
network's **homogenised elastic tensor C6 (6 numbers)**. The directional response
`nu(theta)`, `E(theta)` derives from C6 with the *same* formulas the solver uses
(`c6_to_nuE` / `c6_to_nuE_theta`), so a single C6 prediction gives the whole angular
response. Once trained at scale, M2 replaces expensive solver forward passes inside the
inverse-design search loop.

```
   graph (pts, bonds, k, bond_R)  --[ GNN ]-->  C6 (6,)  --[ exact formula ]-->  nu(theta), E(theta)
```

## Dataset (`build_dataset.py` -> `data/dataset.npz`)

Plain forward-random sampling piles up in the trivial `nu~0.3, E~1.15` blob
(the original `Phase 5/dataset/coverage.png` occupies only **16** cells of the coarse
`(mean nu, mean E)` grid). M2's builder is **coverage-driven**, combining two sources:

- **(A) Forward scan** — every family of the seed zoo (`seeds.seed_pool`: Bravais lattices,
  random patches over 4 point processes — uniform / Poisson-disk / blue-noise / graded —,
  the Archimedean tilings, complex-basis honeycomb/kagome, and auxetic motifs) crossed with
  **four k-patterns**: `k0` (the seed's native/soft-fictional field), `uniform`,
  `lognormal` (structured multiplicative disorder, two sigmas), and `graded` (smooth spatial
  stiffness gradient, two amplitudes). Each labelled by the **solver** forward pass -> C6.
- **(B) Ingest designed networks** — ALL `Phase 5/networks/**/*.npz` (including any `goal1/`,
  `goal2/` produced by sibling runs). Where a network carries an independent-sim per-triangle
  tensor `C6_per`, the label is the **sim** region C6 (`region_phys_C6`); these populate the
  rare, interesting regions (auxetic / anisotropic) the forward scan under-samples.

Each sample stores the full graph (`pts, bond_u, bond_v, bond_R, k, tri_bond, areas,
BL1, BL2`), the label `C6 (6,)`, the derived `nu(theta), E(theta)`, and descriptors
(mean nu, mean E, anisotropy = normalised spread of E(theta)). Everything is concatenated
into one consolidated `data/dataset.npz` (batch-of-graphs pointer scheme).

**Default build result** (modest, ~1.7 min):

| quantity | value |
|---|---|
| total samples | **317** (264 forward, 49 design-sim, 4 design-solver) |
| occupied (nu,E) cells | **19** vs old **16** |
| mean-nu range | [-1.02, +0.91] (incl. auxetic) |

Coverage figure: `data/coverage.png` (blue = forward, red = design-sim, orange =

(`--n_random`, `--n_nodes`, `--scale`) so it scales to a few thousand samples overnight,
which fills substantially more cells (the ingest + graded/lognormal k already break out of
the blob; more topologies widen it further).

## GNN architecture (`model.py`, `ForwardGNN`)

Lightweight **message-passing GNN in PLAIN torch** (`index_add_` scatter) — **no
`torch_geometric` dependency**.

- **Edge features (per bond, 5)**: `[k, log(k+eps), |bond_R|, dir_x, dir_y]`, where
  `bond_R` is the **true periodic bond vector** (already carries the wrap, so the net sees
  the effective periodic connectivity) and `dir = bond_R/|bond_R|`. Each undirected bond
  becomes two directed edges (+R and -R). *(Not rotation-invariant — acceptable for v1.)*
- **Node features**: node degree (scalar), embedded to `hidden`.
- **Message passing** (`n_layers=4`, `hidden=64`): each round computes
  `m = edgeMLP([h_u, h_v, edge])`, scatter-**mean** aggregates messages into the
  destination node, then a residual `nodeMLP([h, agg])` update.
- **Pooling**: global **mean + sum** over each graph's nodes (concatenated).
- **Head**: MLP `2*hidden -> 128 -> 128 -> 6` producing **C6**.

`c6_pred_to_nuE` / `c6_pred_to_nuE_theta` convert a predicted C6 to reporting `nu, E`.

## Training scaffold (`train.py`)

- **Batching**: plain batch-of-graphs — many graphs concatenated into one big graph with a
  `batch` vector mapping each node to its graph id (no PyG).
- **Loss**: MSE on the 6 C6 components, each **normalised by its train-split std**.
- **Split**: 80/20 train/val (seeded).
- **Reported metric**: val **MAE on the derived nu and E** (from predicted C6), plus a
  train/val loss curve and a predicted-vs-true scatter.
- **Checkpoint**: `checkpoint.pt` stores weights + C6 mean/std + config.

Run: `python "Phase 5\m2\train.py"` (see `README.md` for flags).

## Next steps (to a converged model)

1. **Scale the data.** `build_dataset.py --scale` (or `--n_random 500 --n_nodes 160`) to a
   few thousand samples overnight; add more k-patterns and more auxetic/anisotropic ingests.
   Aim to fill far more than 19 (nu,E) cells and to balance the rare regions.
2. **Train longer / bigger.** `--epochs 800 --hidden 128 --n_layers 5`; add LR warmup and
   early stopping on val. Consider per-component C6 loss weighting.
3. **Better inductive bias.** Add rotation-invariant edge features (drop raw dir, keep
   angle differences), triangle-level features (areas/angles) toward the simplicial GNN in
   PLAN §9, and physically constrain C6 to be SPD.
4. **Validate honestly.** Hold out entire topology *families*, and check the surrogate's
   nu(theta),E(theta) against the independent sim (not just the solver labels it trained on).
5. **Wire into design.** Use M2 as a fast pre-filter / gradient source inside the M1
   inverse-design search to cut solver calls.
